# SCSS / Gulp / Profile Clone

Live Demo: [https://joudhijaz.github.io/SCSS-Gulp-task-profile-clone/](https://joudhijaz.github.io/SCSS-Gulp-task-profile-clone/)

## 📌 Overview
A responsive Facebook-style profile page clone built using **HTML**, **SCSS**, and **Gulp**.  
This project focuses on modular SCSS architecture, clean UI design, and automating repetitive tasks using Gulp.

## 🚀 Features
- Responsive layout and design
- SCSS for organized, maintainable styles
- Gulp for live server, SCSS compilation, and task automation
- Avatar/profile layout with editable sections
- Clean, component-based code structure

## 🛠️ Technologies Used
- HTML5
- SCSS (Sass)
- Gulp
- JavaScript (basic interactivity)
- Live-server / browser-sync
